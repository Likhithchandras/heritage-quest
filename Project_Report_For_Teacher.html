Academic Project & Hackathon Submission Report

Heritage Quest

Gamified Real-World Heritage Exploration Platform with GPS Geofencing, QR Ciphers & AI Historical Guide

Node.js / Express Native SQLite Leaflet GPS Radar Html5Qrcode Contextual AI RAG Web Audio & Speech API

1. Problem Statement & Motivation

Core Problem: Heritage sites are valuable sources of history and culture, but most visitors experience them passively — viewing static placards or reading generic brochures without discovering the deeper narrative. Traditional mobile guides offer simple multiple-choice quizzes that fail to engage explorers physically on the monument grounds.

Proposed Solution: Heritage Quest transforms ancient forts, palaces, and temples into interactive physical adventure grounds. Visitors become active field researchers who navigate the site using GPS proximity radar, scan real-world stonemason QR markers, complete geometric lintel puzzles, interrogate historical ghost NPCs, consult an AI Heritage Scribe, and earn cryptographically verified Discovery Certificates.

2. System Architecture

The platform follows a modular, client-server decoupled architecture designed for both online and offline operation inside thick monument walls:

Component Technologies Role & Capabilities
Backend API Server Node.js, Express.js REST API for sessions, checkpoint logic verification, hints penalization, live leaderboards, and admin analytics.
Database Engine Native SQLite (node:sqlite) Persistent storage of historical quests, 40m geofence coordinates, player sessions, scores, and lore archives.
GPS Geofencing Engine Leaflet.js, Haversine Distance Calc Real-time proximity calculation between player coordinates and monument checkpoints with Demo Mode bypass.
Vision & QR Subsystem Html5Qrcode, QRCode.js Live camera QR scanner + Game Master 4-Up printable marker sheet generator.
AI Heritage Guide Contextual RAG & Knowledge Base Historical query processor answering questions about rulers, architecture, and clues.
Audio & Accessibility Web Speech API, Web Audio API Reads court scribe journals aloud with synthetic temple bells, drums, and seal pop sound effects.
Discovery Certificate HTML5 Canvas 2D API Renders high-resolution printable parchment certificates with royal wax seals and SHA-256 verification codes.

3. Key Expeditions Included

  • The Lost Royal Seal (Vijayanagara / Hampi) — Recover the vanished 16th-century royal seal by decoding the Durbar archway, Mason-108 cipher, alternating lintel pattern, and the Armoury Ghost.
  • The Nizam's Secret Vault (Golconda Fort, Hyderabad) — Decode Fateh Darwaza acoustic whispering arches, granary grain chest markers, diamond facet geometry, and the Citadel Sapper.
  • The Celestial Code of Konark (Sun Temple, Odisha) — Solve the 24 astronomical sundial wheels, lodestone calibration, and the legend of master builder Dharmapada.
  • Community Custom Quests — Visual Game Master studio allows teachers and curators to create local treasure hunts and export printable QR markers.

4. How to Run & Present to the Teacher

  1. Open the project folder and double-click START_HERITAGE_QUEST.bat (or run npm start in terminal).
  2. Open browser at http://localhost:3000.
  3. Live Demo Steps:
    • Select The Lost Royal Seal and enter your team name.
    • Click 🗺️ Map to showcase the Leaflet GPS Radar.
    • Demonstrate Checkpoint 1 (MCQ Inscription), Checkpoint 2 (QR Camera Scanner), and Checkpoint 3 (Symbol Pattern).
    • Click the 🤖 AI Guide button and ask a historical question.
    • Solve Checkpoint 4 and complete the Final Reconstruction.
    • Click 📜 View Discovery Certificate to display and download the signed Certificate.
    • Open the Game Master Studio to show the Printable QR Marker Sheet and Custom Quest Creator.
